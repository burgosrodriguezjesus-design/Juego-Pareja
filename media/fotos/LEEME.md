# Fotos

Mete aquí las fotos y luego las llamas desde `contenido/historia.js`.

```js
escena:   { foto: "media/fotos/la-playa.jpg" }   // fondo del capítulo
recuerdo: { foto: "media/fotos/nosotros.jpg" }   // la foto del recuerdo
```

**Consejos:**

- Nombres sin espacios ni acentos: `primera-cita.jpg`, no `Primera Cita (1).JPG`
- Para fondos: apaisadas y grandes (1600px de ancho va bien)
- Para recuerdos: cualquier forma; se muestran tipo polaroid
- Para el `puzzle`: **cuadradas**, o saldrán estiradas
- Cómprimelas un poco. Una foto de 8 MB tarda en cargar en el móvil;
  con 300–600 KB se ve perfecta.

Si una foto falta o está mal escrito el nombre, el juego sigue funcionando:
simplemente no la enseña.
